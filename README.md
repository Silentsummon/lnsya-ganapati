# LNSYA Ganpati Celebration App

React + Vite + Supabase web app for managing the Ganpati celebration.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:5173

## Login PINs
- President: 5678
- Treasurer: 1234
- Volunteer: 9999

## Deploy
```bash
npm run build
vercel --prod
```
